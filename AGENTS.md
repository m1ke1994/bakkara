# Repository instructions

- Work directly on the `main` branch. This is the user's explicit repository workflow.
- Do not create feature branches or open pull requests unless the user explicitly requests an exception.
- Publish completed, verified changes to `main` and provide local update commands for `main`.
- Preserve the user's local SQLite history when providing update commands. Never replace it with the repository copy or use `git reset --hard` to resolve local changes.
